# 51macc 数据采购需求清单(2026-09-24)

> 可打印/转发版:`workspace/sql-batch/macc-data-procurement.html`
> 需方:济南德达汽车配件有限公司(重卡配件贸易商,自有线上目录 1.2万+ SKU,44 家经销渠道)

## 采购目标
商用车配件数据库**批量数据授权导出**(非 API 按次调用),用于内部目录增强、配件查询与客户服务。

## 数据范围与字段(以 API 实测返回为准)
1. **车型库**:VIN 解析规则、modelId、车型名、品牌、厂家、publicCode、年份、车型描述(重卡优先:解放/重汽/陕汽/东风/福田)
2. **配件 BOM 明细**(核心):OE 图纸号、原厂名、标准名、别名、英/俄译名、用量、分组归属、图片地址——按车型全量
3. **三级分组字典**:分组树 + 中/英/俄三语
4. **价格(可选)**:厂价/售价/零售 + 供应商报价(含联系方式);需谈时效与更新

## 交付格式
CSV/SQL/JSON(UTF-8);首次全量 + 增量更新机制(频率/方式/费用);附数据字典。

## 授权范围
内部使用(目录增强/站内搜索/客户查询/内部工具);不转售、不再分发原始数据;可接受来源标注。

## 商务问题清单
1. 计价:买断 / 年费 / 车型×数据块计价?
2. 能否提供覆盖清单(品牌×车型×年代)评估?
3. 更新频率与费用?
4. 授权用户数/站点数?
5. 能否先给若干车型完整 BOM 样本导出验证?

## 锚点
已是 API 付费用户,采购意愿真实;批量可行则长期续费,否则维持按次。
